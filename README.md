# AI Poem Generator

The AI Poem Generator transforms a simple word into a creative six-line poem using artificial intelligence. Users enter a word, submit it, and receive an original poem generated in real time. This project demonstrates API integration, asynchronous JavaScript, and responsive front-end development.

## Live Demo

Access the application here: https://naniki-dev.github.io/AI-Generator/

## Features

* Generate a six-line poem from a single word
* AI-powered content generation
* Responsive and user-friendly interface
* Real-time API requests and responses
* Clean and minimal design

## Tech Stack

* HTML
* CSS
* JavaScript
* SheCodes AI API

## How It Works

1. Enter a word in the input field.
2. Submit the form.
3. The application sends the word to the SheCodes AI API.
4. The AI generates a six-line poem based on the provided word.
5. The poem is displayed on the page.
